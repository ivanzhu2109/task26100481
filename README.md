# vecindex

进程内向量索引库，支持文档增量更新期间的在线滚动重建。输入为 32 维单位向量，
检索为对选定检索代的全量余弦打分（不近似）。

## API

- `Upsert(docID, tags, vectors) uint64`：原子替换文档的标签与全部分块，返回严格递增的修订号。
- `Delete(docID)`：原子删除；同一 docID 可重新写入，不继承旧分块。
- `Search(q, tag) []SearchResult`：仅检索含 `tag` 的文档，返回余弦分 ≥ 0.35 的前 20 个分块，
  同分按 docID、分块序号升序。结果含文档 ID、分块序号、修订号、分数。
- `Rebuild()`：从权威文档记录构造独立新检索代并在线切换，切换完成后返回。
  同一时刻至多一个 Rebuild 在运行，并发调用者等待其完成后直接返回。

## 设计

- **权威记录**：`docs` 链表 + 哈希表，由 `mu` 保护。记录一旦提交即不可变，
  Upsert 以新记录整体替换。
- **检索代（generation）**：分片哈希表，每个文档一条不可变版本链（含删除墓碑）。
  提交路径把每个变更作为新版本推入当前服务代与重建中的代（增量 delta），
  因此 Upsert/Delete 是 O(分块) 的，绝不复制全库。
- **Search**：先读全局提交序号作为水位线，再读服务代指针；按分片拷贝
  (docID, 链头) 快照后无锁打分。已选定视图被暂停时不持有任何锁，
  修改、其他查询与重建切换都能继续。版本链按水位线解析，保证结果等价于
  调用期间某一时刻对完整已提交集合的检索。
- **Rebuild**：分批（256 条/批）在锁内读取记录指针、锁外回填；回填写入前
  按修订号比较，旧修订绝不覆盖经 delta 路径到达的新修订，删除不会被复活。
  回填结束后在 `mu` 下原子切换服务代。两代共享不可变向量字节，
  但不共享任何可原地修改的检索状态。

## 测试诊断

- `CurrentGenerationID()`：当前服务代编号。
- `SearchesInGeneration(id)`：选定某代为视图的查询次数，用于确认切换后
  查询确实落在物化的新代上。
- 测试钩子（同包白盒）：`hooks.onBackfillDoc`（回填已读未写处暂停）、
  `hooks.onSearchView`（查询已选定视图未打分处暂停），均以同步屏障实现，
  不依赖 sleep。

## 运行测试

```sh
go test ./...        # 全部测试
go test -race ./...  # 竞态检测
```

包含：基础语义、回填暂停期间改标签/向量→删除→同 ID 不同分块数重写、
已选定视图查询暂停期间完成替换/删除/重建切换、5 万文档 ×4 分块在重建期间
并发修改与查询并与独立顺序参考实现逐条核对。

## 已知限制

版本链不做垃圾回收（长服役代上频繁更新的文档会累积旧版本）；
无持久化与崩溃恢复（按需求范围）。
