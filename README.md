# vecindex

进程内向量索引库（Go），输入为 32 维单位向量，支持文档增量更新期间的在线滚动重建。

## API

- `Upsert(docID, tags, vectors) (rev, error)`：原子替换文档的标签与全部分块向量（`len(vectors)` 必须是 32 的倍数，分块序号按输入顺序），返回严格递增的修订号。
- `Delete(docID)`：原子删除文档，之后允许用相同 ID 重新写入。
- `Search(q, tag)`：只检索包含 `tag` 的文档，返回余弦分数 ≥ 0.35 的前 20 个分块，同分按 `(docID, chunk)` 升序；结果含文档 ID、分块序号、修订号、分数。
- `Rebuild()`：从权威文档记录构造独立的新检索代并在线切换，完成后返回；同一时刻至多一个 Rebuild。
- `Stats()` / `WithHooks(...)`：测试诊断（当前检索代 ID、回填/视图选择屏障钩子）。

## 设计要点

- 每次提交生成不可变版本节点（标签 + 修订号 + 分块向量），写入权威记录与活跃检索代；Search 固定一个已提交修订号，只读不可变节点，打分不持锁，结果等价于某一时刻的完整检索。
- Rebuild 期间活跃修改双写进新代；回填的旧修订通过修订号比较永远输给新提交，删除不会被回填复活，ID 复用不会继承旧分块。
- 切换后旧代不再被写入，仍在执行的查询在其选定视图上完成；两代只共享不可变向量字节。

## 测试

```sh
go test ./...        # 全部测试
go test -race ./...  # 竞态检测
```

包含：同步屏障复现的回填暂停与查询视图暂停场景、5 万文档 × 4 分块在重建期间并发修改与查询并对照独立顺序参考实现的压测。
